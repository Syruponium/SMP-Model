# Galactic Rotation & Thermal Gradients: An Empirical Inquiry

## Abstract
This repository presents an observed correlation between galactic rotation curve characteristics and bolometric luminosity. Analysis of 25+ diverse galaxies suggests that the "halo radius" ($R_{snap}$)—the point where rotation curves deviate from Newtonian expectations—scales with total energy output ($L_{bol}$) according to a specific power law.

We are sharing this data to explore whether these dynamics can be modeled as a **thermal phase transition** within a superfluid vacuum medium.

## The Core Observation: $L^{0.344}$ Scaling
Through iterative curve-fitting of 25+ galaxies (ranging from dwarf spheroidals to giant spirals), we have identified a consistent scaling relationship:

$$R_{snap} \propto L_{bol}^{0.344}$$

The stability of this exponent (ranging between $0.33$ and $0.35$) across vastly different galactic environments suggests a shared underlying physical mechanism.
